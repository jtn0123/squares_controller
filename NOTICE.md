# Attribution notice

Squares Controller is an independent, MIT-licensed controller for stock
Twinkly Squares hardware.

The product roadmap was informed by concepts made familiar and useful by the
[WLED project](https://github.com/wled/WLED), including:

- Presets and timed playlists
- Color palettes
- Segments, represented here as wall, panel, row, column, and rectangle zones
- Effect transitions and layered effects
- 2D and particle-style effects
- Timers, schedules, and local automation
- A machine-readable local JSON control API

This is conceptual attribution, not a declaration that Squares Controller is
a derivative of WLED. Squares Controller contains no WLED firmware, source
code, web interface assets, or branding. Its transport, server, browser UI,
effects, tests, and Twinkly-specific behavior were implemented independently.
