# Contributing

Thanks for helping improve Squares Controller.

1. Create a focused branch.
2. Keep controller addresses and network captures out of commits.
3. Run `npm test`.
4. Describe the panel arrangement and firmware used for hardware testing.
5. Open a pull request with the behavior change and verification notes.

Please keep runtime dependencies at zero unless a dependency has a clear,
documented benefit. Never add cloud connectivity or telemetry without an
explicit design discussion.
